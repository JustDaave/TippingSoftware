QuietTip - Low-Fidelity Prototype (HCI class assignment)
=========================================================

HOW TO OPEN
-----------
Keep index.html, styles.css, and script.js in the same folder.
Double-click index.html (or drag it into any modern browser).
No server, installation, or internet connection is needed.

SCREENS
-------
1. Prototype start - choose "Customer experience" or "Employee transparency demo"
   (navigation choices, not login roles).
2. Completed purchase and receipt - sample $20 cafe receipt, "Optional: leave a
   tip later" section with a QR code placeholder and "Try optional tipping",
   and "Finish".
3. Optional tip page - No tip / $1 / $2 / $3 / Custom, nothing preselected;
   "Where tips go", "Leave feedback without tipping", "Finish without tipping".
4. Tip distribution - fictional sample pooling policy with a four-box diagram.
5. Review tip - purchase, tip (separate simulated payment), combined total;
   "Edit amount", "Confirm simulated tip", "Cancel tip".
6. Completion - neutral message, "Finish without feedback", and optional
   feedback form (after submitting, a confirmation with "Finish").
   Both finish buttons lead to a final "All done." screen.
7. Employee transparency demo - aggregate fictional pool and equal shares.

SIMULATED DATA
--------------
All transactions, receipts, tips, feedback, and employee data are simulated.
No money is charged, no payment or personal information is collected, and
nothing is sent to any server or external service.

RESET ON REFRESH
----------------
State is kept only in JavaScript memory. Refreshing or reopening the page resets
all selections, feedback, and simulated tips, and returns to the prototype start.
